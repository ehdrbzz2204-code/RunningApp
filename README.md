# RunningApp
목표 기반 러닝 미션 앱

## 백엔드 MVP

1. 러닝 기록 저장 및 오프라인 재전송 시 중복 방지
2. 3km 자유 주행 3회 확인 및 초기 체력 산출
3. 사용자별 거리 또는 페이스 목표 저장
4. 맞춤 미션 추천 및 성공 여부 판정
5. 주간·월간 러닝 기록 조회

## 모바일 앱과 서버의 역할

- 모바일 앱은 GPS 측정, 로컬 저장, 연결 복구 후 재전송을 담당합니다.
- 서버는 러닝 기록, 초기 측정 진행률, 활성 목표, 미션 결과를 관리합니다.
- API에서 거리는 m, 시간은 초, 페이스는 초/km를 사용합니다. 앱은 동일 러닝을 재전송할 때 같은 `clientRunId`를 사용합니다.

## 협업

작업 브랜치에서 변경하고 Pull Request로 `main`에 합칩니다. 기술 스택과 실행 방법은 백엔드 코드가 추가될 때 문서화합니다.
